## Features

### Core Search Capabilities
- 🔍 **Web Search**: Access 100+ popular sites across 10 categories
- 📝 **Article Preview**: Extract, format with APA cite, summarize articles, PDFs, YouTube, URLs
- 🤖 **Multi-Provider LLM**: Claude, GPT, Gemini, Grok, Llama, Chinese LLMs
- 📄 **File Uploads**: Ask questions about PDFs, URLs, DOCX, Google Docs, YouTube
- 📚 **Search History**: Saved with memory; privacy mode available
- ❓ **Follow-up Questions**: AI-generated questions for deeper research

### Writing Assistant
- 📝 **Complex Rich Text Editor**: Full-featured Lexical-based editor (Google Docs alternative)
- 📂 **Nested Document Tree**: Organize with drag-and-drop, tabs, custom storage
- 🖱️ **Context Menu**: Right-click actions for document management
- 🔍 **Full-Text Search**: Instant document search by title or content
- ✨ **AI Rewriting**: Improve text directly within editor
- 👥 **Team Collaboration**: Manage team members and access rights
- 🔄 **Multiple Views**: Formatted, HTML parsing, Markdown modes
- 🛠️ **Find & Replace**: Search/replace with match highlighting
- 📥 **Google Docs Integration**: Seamless export/import/sharing
- 💾 **Persistent Storage**: SQLite backend for data safety
- ⌨️ **Keyboard Shortcuts**: Efficient navigation for power users
- 💬 **Research Quotes**: Capture and organize key insights

### Content Extraction Tools
1. **Main Content Detection**: Combines Mozilla Readability + Postlight Mercury
2. **YouTube Transcripts**: Complete captions with timestamp sync
3. **PDF to HTML**: Structured conversion with headings, footnotes, TOC
4. **HTML Standardization**: Simplified reading-mode format
5. **Citation Extraction**: Validate against 90k+ name database

### Applications
- 🖥️ **Desktop App**: Tauri-based, text selection + backtick search
- 🧩 **Browser Extension**: AI-powered tab manager
- 🧠 **VS Code Extension**: Sidebar research questions
